# Vrinda Store Data Analysis
# 📌 Project Overview

This project focuses on analyzing Vrinda Store sales data to uncover customer behavior, sales trends, and business insights that can support data-driven decision-making. The analysis involves data cleaning, exploratory data analysis (EDA), and visualization of key performance indicators.

📂 Dataset

# File Name: Vrinda Store Data Analysis.xlsx

Data Type: Retail sales data

# Contents Include:

Order and sales details

Customer demographics (age, gender, location)

Product categories

Order status and channels

# 🛠 Tools & Technologies

Microsoft Excel

Data cleaning and preprocessing

Pivot tables and charts

Summary statistics and trend analysis

# 🔍 Analysis Performed

Data cleaning and handling of missing or inconsistent values

Sales trend analysis by month and category

Customer segmentation based on gender and age group

Channel-wise sales performance analysis

Order status and fulfillment insights

# 📈 Key Insights

Identified top-performing product categories and sales channels

Observed purchasing behavior differences across customer demographics

Highlighted seasonal trends and peak sales periods

Analyzed order completion and cancellation patterns

# 📊 Visualizations

Sales trends over time

Category-wise and channel-wise performance

Customer demographic distribution

Order status breakdown

(All visualizations are created using Excel pivot charts.)

# ✅ Results

The analysis provides actionable insights that can help:

Improve inventory planning

Optimize marketing strategies by customer segment

Enhance channel-wise sales performance

# ▶️ How to Use

Download the Excel file from this repository

Open Vrinda Store Data Analysis.xlsx in Microsoft Excel

Explore the cleaned data, pivot tables, and dashboards

Review insights and visualizations for business understanding
